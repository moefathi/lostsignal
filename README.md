# Lost Signal – Unity Game Development

## Project Overview
Lost Signal is a game development project created using **Unity** and **C#**. The project focuses on developing a playable game for Windows and includes the complete Unity source project, supporting documentation, and a downloadable game build.

## Game Download
The playable Windows version is available through GitHub Releases.
- **Version:** 0.1.0
- **Platform:** Windows
- **Download:** [Lost Signal – Windows v0.1.0](https://github.com/moefathi/lostsignal/releases/download/v0.1.0/Lost.Signal.zip)

### How to Play
1. Download the game ZIP file.
2. Extract the downloaded archive.
3. Open the extracted folder.
4. Run `Lost Signal.exe`.

## Game Development
The project was developed using Unity, with C# used for game programming.
The repository includes the Unity source project, allowing developers to explore the game assets, scripts, scenes, packages, and project settings.

## Unity Project
The Unity source project includes:
- **Assets:** Game resources and development assets.
- **Packages:** Unity packages and dependencies.
- **Project Settings:** Configuration and settings used by the Unity project.

## Windows Build
A standalone Windows build is provided through GitHub Releases. It includes the executable and supporting files required to run the game independently of the Unity Editor.
