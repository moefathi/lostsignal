# Lost Signal – Unity Game Development

## Project Overview
Lost Signal is a 3D first-person educational survival game developed using **Unity** and **C#**. Set on an alien planet, the game follows Captain John as he attempts to rescue Captain Emilie by surviving a series of trials created by an alien boss.

The game combines survival challenges with educational physics concepts, introducing gravity, mass, and projectile motion through gameplay and radio communication.

## Gameplay
Players must explore the environment, avoid falling objects and aliens, and use throwable rocks to overcome obstacles. Through radio communication, Captain Emilie guides the player and explains the physics concepts introduced throughout the game.

### Levels
- **Level 1 – The Road:** Introduces gravity through falling objects.
- **Level 2 – The Alien Road:** Introduces moving aliens and different object masses.
- **Level 3 – The Maze:** Combines gravity, mass, and projectile motion, leading to the rescue of Captain Emilie.

## Game Development
The project was developed using Unity, with C# used for game programming. It uses Unity features such as prefabs, the physics engine, animation system, UI system, audio system, and scene management.

The repository includes the complete Unity source project, allowing developers to explore the game assets, scripts, scenes, packages, and project settings.
